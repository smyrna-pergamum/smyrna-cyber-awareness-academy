# Smyrna Cyber Academy

Une académie multilingue de sensibilisation à la cybersécurité proposant 28 leçons pratiques, des études de cas, des quiz, le suivi de progression, des badges et un certificat de réussite.

## Langues de l’application

L’interface, les leçons, les objectifs pédagogiques, les modules, les questions de quiz, les retours de réponse et les études de cas pédagogiques sont disponibles en turc, anglais, allemand, français, espagnol, arabe et russe.

## Lancer l’application localement

Ouvrez `index.html` dans un navigateur récent. Aucune compilation ni aucun serveur ne sont nécessaires. La progression est enregistrée dans le stockage local du navigateur.
