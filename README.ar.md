# أكاديمية Smyrna Cyber

أكاديمية متعددة اللغات للتوعية بالأمن السيبراني، تضم 28 درساً عملياً ودراسات حالة واختبارات وتتبعاً للتقدم وشارات وشهادة إتمام.

## لغات التطبيق

تتوفر الواجهة والدروس وأهداف التعلم ووصف الوحدات وأسئلة الاختبارات والتغذية الراجعة ودراسات الحالة التعليمية بالتركية والإنجليزية والألمانية والفرنسية والإسبانية والعربية والروسية.

## التشغيل محلياً

افتح الملف `index.html` في متصفح حديث. لا حاجة إلى بناء أو خادم. يُحفظ تقدم التعلم في التخزين المحلي للمتصفح.
