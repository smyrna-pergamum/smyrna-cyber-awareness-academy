# Release notes / Sürüm notları

## v1.0.0 — Initial public release

### English

- Published the cybersecurity awareness academy as a static web app.
- Added 28 lessons with learning objectives, lesson modules, teaching explanations, case studies, and quizzes.
- Added Turkish, English, German, French, Spanish, Arabic, and Russian content and interface translations.
- Added per-profile progress, XP, badges, quiz scores, and completion certificate.
- Added responsive layouts, light and dark themes, and GitHub Pages hosting.
- Progress is stored in the browser's local storage.

### Türkçe

- Siber güvenlik farkındalık akademisi statik web uygulaması olarak yayımlandı.
- Öğrenme hedefleri, ders modülleri, öğretici açıklamalar, vaka çalışmaları ve quizler içeren 28 eğitim eklendi.
- Türkçe, İngilizce, Almanca, Fransızca, İspanyolca, Arapça ve Rusça içerik ve arayüz çevirileri eklendi.
- Profil bazlı ilerleme, XP, rozetler, quiz puanları ve tamamlama sertifikası eklendi.
- Duyarlı tasarım, açık/koyu temalar ve GitHub Pages barındırması eklendi.
- İlerleme tarayıcının yerel depolamasında tutulur.
