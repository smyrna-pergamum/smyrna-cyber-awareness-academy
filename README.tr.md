# Smyrna Cyber Akademisi

28 uygulamalı ders, vaka çalışmaları, quizler, ilerleme takibi, rozetler ve tamamlama sertifikası sunan çok dilli siber güvenlik farkındalık uygulaması.

## Uygulama dilleri

Arayüz, dersler, öğrenme hedefleri, modül açıklamaları, quiz soruları, cevap geri bildirimleri ve öğretici vaka çalışmaları Türkçe, İngilizce, Almanca, Fransızca, İspanyolca, Arapça ve Rusça olarak sunulur.

## Yerel çalıştırma

`index.html` dosyasını güncel bir tarayıcıda açın. Derleme adımı veya sunucu gerekmez. Eğitim ilerlemesi tarayıcının yerel depolamasında saklanır.
